# 许愿墙翻牌动效说明

参考图片：Refer/喀兰圣山许愿墙.jpg

本说明定义「许愿墙抽取页」的三阶段动效与层级结构，目标是：

- 保持静态画面有呼吸感与可交互感
- 选中卡片的动作具有“跃出 + 翻转 + 结果呈现”的仪式感
- 抽取完成后状态明确、可复盘

---

## 第一阶段：静止 / 初始状态（许愿墙待选态）

### 核心视觉

- 所有签牌以未翻开状态规则排列
- 左上角显示剩余可选次数（示例：2/2）
- 可选元素具备明确悬停反馈

### 动效关注点

- 牌面初始位置、角度与间距的一致性
- 进入时可采用 `enter/stagger` 的轻量排入
- 轻微浮动与光泽过渡，强化可交互性

### 动画细节（建议）

- 轻微摆动：全体卡片以低幅度缓动（避免“死板静止”）
- 悬停放大 + 光泽过渡：hover 时轻微放大并提升亮度/反射

### 移动端倾斜交互（新增）

在移动端使用陀螺仪输入，让卡片随手机倾斜产生轻微角度变化，并同步光线角度变化：

- **触发条件**：仅移动端启用；权限未授权时不影响其他动效
- **倾斜范围**：`rotateX/rotateY` 建议控制在 ±4°～±6°
- **平滑**：加低通滤波/插值（避免抖动）
- **光线变化**：通过卡片伪元素的渐变方向/高光位置联动倾斜角
- **无障碍**：尊重 `prefers-reduced-motion`，降低或关闭此效果

### 阶段示意

```

│ [2／2]                               │
│                                     │
│   □   □   □   □   □   □   □   □   □  │
│   □   □   □   □   □   □   □   □   □  │

└─────────────────────────────────────┘
```

> □ 表示未翻开卡，画面平静但具备可交互暗示。

## 第二阶段：抽取中（弹出 + 翻转 + 结果预览）

### 核心视觉

这是动效最“有生命力”的阶段。点击某张后出现“拍出牌堆 → 翻转 → 奖励预览”的完整动作链。

### 动效拆分

**触发链路**：点击 → 选中卡片弹出 → 旋转/翻转 → 奖励显示

#### A. 选中卡片弹出

- 被选中的卡片从队列中跃出
- 带轻微弹性（建议 easing：`cubic-bezier(.34,1.56,.64,1)`）
- 轨迹：原位置 → 画面中央偏上

#### B. 翻转 Reveal

- 卡片背面 flip → 正面
- 使用 3D 旋转实现顺滑翻转

```
┌─────────────┐
|             |
|   BACKSIDE  |
|             |
└─────────────┘ → 翻转 → ┌────────────┐
                        |            |
                        | REWARD UI  |
                        |            |
                        └────────────┘
```

#### C. 结果浮现 + 状态变化

- 奖励图标 / 数值淡入并轻微上浮
- 结果停留 0.8–1s，形成仪式感

## 第三阶段：抽取完成 / 已领取状态

### 核心视觉

- 已抽取卡片显示“完成标记”
- 剩余次数更新为 0/2 或“已抽取”
- 已抽取卡片变灰、失去交互

### 动效重点

- 卡片可选择“飞回原位”或直接淡出
- 更新剩余次数与按钮状态

### 可选增强

- 奖励数字或图标轻微放大
- 稀有奖励触发轻量粒子效果

### 阶段示意

```
┌─────────────────────────────────────┐
│ [0／2]                               │
│                                     │
│  ❌    □    □   □   □   □   □   □   □  │
│       □    □   □   □   □   □   □   □  │
│                                     │
│          已抽取提示按钮             │
└─────────────────────────────────────┘
```

> ❌ 表示已抽取的牌，□ 表示未抽取状态。

## 动效时序与 easing 建议

| 阶段 | 时间 | easing 建议 |
| --- | --- | --- |
| 初始轻微摆动 | 3s 循环 | ease-in-out |
| 弹出 / 跳跃 | 0.3s | cubic-bezier(.34,1.56,.64,1) |
| 翻转 Reveal | 0.5s | linear |
| 奖励停留 | 0.8–1s | ease-out |
| 已领取淡出 | 0.4s | ease-in |

---

## 动画分层结构（便于实现）

我们使用 4 层 UI 进行解耦：

- **UI Layer 1**：抽取次数 / 信息文本
- **UI Layer 2**：许愿墙卡片阵列
- **UI Layer 3**：选中卡片弹出层
- **UI Layer 4**：奖励展示 / 粒子特效（可选）

每层可独立控制动效，利于复用与配置化。

---

## 核心动效块（便于 DSL）

| 动效块 ID | 名称 | 作用 |
| --- | --- | --- |
| wall_idle | 初始静态版 | 牌堆轻呼吸 + hover |
| card_pickup | 弹出翻牌动作 | 用户点击后动画 |
| result_reveal | 结果展示 | 显示奖励 + 返回 |

## 配置化动效参数（建议结构）

> 以配置驱动动效，便于调参、A/B 测试与不同活动复用。

```ts
export const motionConfig = {
    idle: {
        swayDuration: 3000,
        swayAmplitude: 1.5,
        hoverScale: 1.03,
        hoverGlow: 0.2,
    },
    pickup: {
        duration: 300,
        easing: 'cubic-bezier(.34,1.56,.64,1)',
        lift: 48,
    },
    flip: {
        duration: 500,
        easing: 'linear',
        perspective: 900,
    },
    reveal: {
        duration: 900,
        easing: 'ease-out',
        floatY: -6,
    },
    settle: {
        duration: 400,
        easing: 'ease-in',
        fadeTo: 0.6,
    },
    tilt: {
        enabled: true,
        maxAngle: 6,
        smoothFactor: 0.08,
        lightShift: 0.25,
    },
}
```
